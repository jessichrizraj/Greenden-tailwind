# 🌿 GreenDen – Plant Shopping Website

## 🌱 Project Overview

GreenDen is a modern and visually appealing plant shopping website developed using **HTML5 and Tailwind CSS**. This project is designed to provide a simple and enjoyable online browsing experience for people who love plants, gardening, and nature.

The website focuses on showcasing a variety of plants through an attractive and well-organized interface. It features a clean layout, beautiful color combinations, stylish typography, and responsive design to make the website look appealing across different screen sizes.

GreenDen represents a simple online plant store where users can explore different plants, discover greenery, and get inspired to make their surroundings more natural and beautiful.

This project was developed as part of my frontend development learning journey to improve my knowledge of HTML and Tailwind CSS and gain practical experience in building modern websites.

## 🎯 Project Objectives

The main objectives of this project are:

- To create a visually attractive plant shopping website.
- To understand the fundamentals of Tailwind CSS.
- To practice writing clean and structured HTML code.
- To develop responsive website layouts.
- To improve frontend development and UI design skills.
- To understand how modern websites organize their content and sections.
- To gain practical experience in building real-world website designs.

## ✨ Key Features

### 1. Attractive Homepage
A beautiful homepage with an appealing design that introduces the GreenDen brand and provides an engaging first impression.

### 2. Navigation Bar
A simple and user-friendly navigation bar that helps visitors explore different sections of the website easily.

### 3. Plant Collection
An attractive product display section where users can explore different varieties of plants with images and descriptions.

### 4. Product Presentation
A clean and organized layout for displaying plant products in an attractive way.

### 5. Responsive Design
The website layout is designed to adapt to different screen sizes, providing a better browsing experience on desktops, tablets, and mobile devices.

### 6. Modern UI Design
Uses attractive colors, proper spacing, typography, and layouts to create a fresh and nature-inspired visual experience.

### 7. Tailwind CSS Styling
Uses Tailwind CSS utility classes to create layouts, manage spacing, apply colors, and style different website components efficiently.

## 🛠️ Technologies Used

### HTML5
HTML5 is used to create the basic structure and content of the website. It helps organize different sections, images, headings, paragraphs, and navigation elements.

### Tailwind CSS
Tailwind CSS is used to design and style the website. It provides utility classes that make it easier to create responsive layouts, manage spacing, customize colors, and build attractive user interfaces.
